# 🛡️ CyberTip

> Plain-English cybersecurity guides for beginners.

**CyberTip** is a learning project that breaks down complex cybersecurity frameworks into simple, practical explanations. It is built for people who are new to the field and want to understand compliance and security without the jargon.

---

## 📚 What You Will Find Here

- **ISO/IEC 27001** — the international standard for information security management
- **DORA** — the EU regulation for digital operational resilience in finance
- **NIS2** — the EU directive for cybersecurity in critical sectors
- **Framework comparisons** — how ISO 27001, DORA, and NIS2 overlap and where they differ

- [ISO/IEC 27001 — Information Security Management](./iso-27001.html)
- [DORA — Digital Operational Resilience](./dora.html)
